DEPLOYMENT (SUPER EASY!)
================================================================================

1. Push to GitHub:
   git init
   git add .
   git commit -m "Portfolio website"
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main

2. Go to vercel.com:
   - Sign up with GitHub
   - Click "Import Project"
   - Select your portfolio repo
   - Click "Deploy"

3. Done! Your site is live at portfolio.vercel.app 🚀

See DEPLOYMENT.md for more details.
